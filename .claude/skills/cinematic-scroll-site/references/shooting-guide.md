# 촬영 가이드 페이지 (guide.html)

고객이 주차장에서 휴대폰을 한 손에 들고 보며 따라 찍는 페이지. 템플릿 `src/guide/*`가 완성본이다.

## 촬영 컷 (shots.json)

- 외관 필수 8장: 정면(0°) → 앞 대각선 운전석(45°) → 운전석 측면(90°) → 뒤 대각선 운전석(135°) → 후면(180°) →
  뒤 대각선 조수석(225°) → 조수석 측면(270°) → 앞 대각선 조수석(315°). 시계 반대 방향으로 한 바퀴, 모두 같은 높이(헤드라이트)·거리.
- 실내 필수 4장: 운전석(운전석 문 밖) → 대시보드(뒷좌석 가운데) / 센터콘솔(조수석 문 밖) → 뒷좌석(뒷문 밖). 9→10, 11→12 로 영상 보간.
- 디테일 선택 5장: 휠, 헤드라이트, 테일램프, 엠블럼, 튜닝·옵션 부품.
- `cameraPosition.angleDeg`: 차 앞 0°, 위에서 볼 때 시계 반대 방향(90 = 운전석/왼쪽). 도식 좌표는 여기서 계산한다.
- `usedFor`(어떤 AI 장면에 쓰이는지)는 내부용 — 공개 번들에서 제거.

## 페이지 구성 (모바일 우선, 그림 먼저)

1. 인트로: "내 차 촬영 가이드" / "휴대폰 하나면 충분해요. 15분이면 끝나요." / 필요한 것 3가지 + 촬영 시작 버튼
2. 꼭 지켜주세요(아이콘 + 이유 한 줄): 가로 촬영 / 1배 렌즈(광각 금지) / 같은 높이 / 카톡 '원본' 전송
3. **촬영 위치 도식**(핵심): 위에서 본 차 SVG + 번호 버튼(진짜 `<button>`, 44px, 퍼센트 좌표로 SVG 위에 겹침) +
   도는 방향 화살표. "앞", "운전석" 라벨. 실내 번호는 점선 테두리로 구분. 번호 → 카드로 스크롤, 화면 가운데 카드 번호 강조.
   PC 에서는 도식을 왼쪽에 sticky.
4. 팁 아이콘 카드(번호 없이) + O/X 비교 3쌍(거리·높이·배경). 예시 사진이 없으면 자리표시자 — `public/guide/`에 파일만 넣으면 바뀜.
5. 컷 카드: 번호·이름·예시 사진·찍는 법·필수/선택 배지·"찍었어요" 체크.
6. 한 장씩 촬영 모드(`<dialog>`): 미니 도식, "찍었어요 → 다음", 이전·건너뛰기, 진행 3/12, 선택 컷은 "선택 1/5", 끝나면 빠진 필수 컷 안내.
7. 보내기 전 체크리스트(필수 12장 자동 계산 + 수동 3개) + 카카오톡 보내기 버튼 + 원본 전송 방법.

## 구현 메모

- localStorage 읽기·쓰기는 전부 try/catch, 실패하면 메모리에만 두고 "저장되지 않아요" 안내.
- 화면 가운데 카드 강조: IntersectionObserver(rootMargin -30%)로 후보를 모으고, 그중 중심이 화면 중앙에 가장 가까운 카드.
  (위쪽 띠 기준으로 고르면 한 칸 앞 번호가 강조되는 버그가 있었다)
- `[hidden]{display:none!important}` — 없으면 촬영 모드의 숨긴 버튼 줄이 함께 보인다.
- 아래 고정 진행 막대(dock)는 맨 위 시작 버튼이 안 보이고 보내기 섹션 전일 때만.
